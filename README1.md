# Dynamic DataFrame Transformation Framework in PySpark

## Overview

This project provides a configurable PySpark-based framework to apply dynamic DataFrame transformations and actions using a JSON-driven approach.

## Features

- Configurable transformations via JSON
- Supports actions like show, write, collect
- Custom transformation logic supported
- Lazy evaluation optimized (Catalyst Optimizer)
- Optional caching and partitioning
- Extensible and modular codebase
